# Furbot — Pet para Codex

Pacote personalizado criado a partir dos modelos 3D `_furbot.blend`,
`_furbot.dae`, `_furbot.obj`, `_furbot.mtl` e `_furbot.stl`.

## Conteúdo necessário

- `pet.json`
- `spritesheet.webp` — 1536 × 1872 px, 8 colunas × 9 linhas, com transparência

## Instalação manual

1. Copie esta pasta para `~/.codex/pets/furbot`.
2. Reinicie ou atualize o Codex.
3. Abra **Configurações → Aparência → Pets**.
4. Selecione **Furbot**.

As linhas da folha representam, nesta ordem: parado, deslocamento à direita,
deslocamento à esquerda, acenando, pulando, falha, esperando, trabalhando e
revisando.

Os arquivos `spritesheet-source.png`, `spritesheet-chroma.png`,
`spritesheet-alpha.png`, `preview.png` e a pasta `reference/` são materiais de
produção e não precisam ser copiados para a pasta de Pets.
