Título: GRAFIK: APLICATIVO COM REALIDADE AUMENTADA PARA EXPLORAÇÃO INTERATIVA DE CONCEITOS DE COMPUTAÇÃO GRÁFICA. 

Resumo: O avanço das tecnologias de Realidade Aumentada tem proporcionado novas formas de ensino interativo no campo da computação. Este trabalho apresenta o GRAFIK, um aplicativo desenvolvido para dispositivos iOS que utiliza Realidade Aumentada com o objetivo de auxiliar no aprendizado introdutório de conceitos de Computação Gráfica, como transformações geométricas homogêneas, câmera sintética e iluminação. A metodologia adotada inclui o uso do framework RealityKit, com exercícios interativos guiados por interface flutuante e renderização de objetos 3D em ambiente físico. O desenvolvimento seguiu princípios de usabilidade e validação prática com usuários, permitindo observar o engajamento e a compreensão dos conceitos abordados. Os testes indicaram que os exercícios funcionaram corretamente, com destaque para os módulos de transformações e câmera. Apesar de limitações no exercício de iluminação, os usuários avaliaram positivamente a experiência, confirmando que o aplicativo cumpriu seus objetivos educacionais.

Título: EXPOFRITZ ACESSÍVEL: APLICATIVO PARA PESSOAS COM DEFICIÊNCIA VISUAL  

Resumo: Este trabalho visa o desenvolvimento de um aplicativo móvel acessível voltado à identificação de objetos físicos em ambientes de acervo, com foco na inclusão de pessoas com deficiência visual. A solução utiliza a câmera do dispositivo para capturar imagens em tempo real e aplica um modelo de rede neural convolucional MobileNetV2, treinado com TensorFlow, para realizar a classificação dos objetos. O modelo foi convertido para o formato compatível com a biblioteca Barracuda e integrado ao Unity, permitindo a inferência diretamente no dispositivo, sem necessidade de conexão com a internet. A aplicação fornece feedback imediato ao usuário por meio de síntese de voz, indicando o objeto detectado. Os testes realizados demonstraram precisão satisfatória no reconhecimento de diferentes objetos, confirmando a viabilidade do uso da inteligência artificial embarcada em dispositivos móveis como ferramenta de acessibilidade.

Título: AR LAB: APLICATIVO DE REALIDADE AUMENTADA PARA AUXILIAR NO APRENDIZADO DOS PRINCIPAIS EQUIPAMENTOS UTILIZADOS EM UM LABORATÓRIO DE QUÍMICA  

Resumo: Este trabalho tem como objetivo desenvolver um aplicativo educacional com uso de Realidade Aumentada (RA) para auxiliar estudantes no aprendizado das principais vidrarias de um laboratório de Química, especialmente em escolas que não possuem infraestrutura laboratorial. A metodologia empregada envolveu levantamento bibliográfico, elicitação de requisitos, modelagem 3D no Blender, desenvolvimento com o motor de jogos Unity integrada ao Vuforia e testes com usuários em parceria com o projeto Habitat e Meninas Digitais. Os resultados demonstraram que o aplicativo permitiu a visualização tridimensional das vidrarias e simulações de reações químicas, promovendo maior engajamento dos alunos. Conclui-se que a ferramenta proposta é viável, acessível e eficaz como recurso didático complementar, contribuindo para o ensino experimental de Química em ambientes escolares com limitações estruturais.
